# PiContent P0 Authoring

PiContent P0 starts with declaration objects and builder plans. Runtime systems consume the declarations later; PiContent itself does not instantiate renderer backends, encode network payloads, or mutate gameplay state.

## Layers

1. Repository and Forge template baseline.
2. Item authoring plans.
3. Block authoring plans.
4. BlockEntity authoring plans.
5. Datagen declaration bundle.
